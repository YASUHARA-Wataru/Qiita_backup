## ツールに関して
### ツールの目的
Qiitaの記事をMarkdown形式でバックアップするPythonツール

### 環境変数の設定
環境変数の、QIITA_ACCESS_TOKENにQiitaのAPI_TOKENを設定してください。

### usage
uv run python main.py --mode github --output ../qiita_github_backup
uv run python main.py --mode local --output ../qiita_local_backup
